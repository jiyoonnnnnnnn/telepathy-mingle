# 텔레파시 게임

멘토링 랩업용 실시간 팀 게임이에요. 참가자는 QR로 들어와 휴대폰으로 투표하고, 진행자는 프로젝터 화면으로 진행해요.
GitHub Pages(화면)와 Firebase(실시간 데이터)만 쓰고, 서버는 없어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 참가자 화면 (QR로 들어오는 곳) |
| screen.html | 진행 화면 (프로젝터용, 사운드, 연출) |
| admin.html | 관리자 페이지 (팀, 문제, 점수 설정, 실시간 현황) |
| common.js | 공용 로직 (점수 계산, 진행 동작) |
| firebase-config.js | Firebase 연결 값 (직접 채워 넣기) |
| database.rules.json | Firebase 보안 규칙 (콘솔에 붙여 넣기) |

---

## 1단계. Firebase 프로젝트 만들기 (10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름 예: oy-telepathy). 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 > Realtime Database > 데이터베이스 만들기**
   - 위치: **싱가포르(asia-southeast1)**
   - **잠금 모드로 시작** 선택
3. Realtime Database의 **규칙** 탭에서 내용을 모두 지우고 `database.rules.json` 내용을 붙여 넣은 뒤 **게시**
4. **빌드 > Authentication > 시작하기**
   - 로그인 방법에서 **익명** 사용 설정 (참가자용)
   - **이메일/비밀번호** 사용 설정 (관리자용)
5. Authentication **사용자** 탭 > **사용자 추가**에서 관리자 계정(내 이메일, 비밀번호)을 만들어요. 만든 뒤 표에 보이는 **사용자 UID**를 복사해 둬요.
6. Realtime Database **데이터** 탭에서 관리자 등록
   - 맨 위 주소 옆 **+** 를 눌러 키 `admins` 추가
   - 그 아래에 키: 복사한 UID, 값: `true` (따옴표 없이 true)
7. 프로젝트 설정(톱니바퀴) > **내 앱 > 웹 앱 추가(</>)** > 앱 등록
   - 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여 넣어요.
   - `databaseURL`이 없으면 Realtime Database 데이터 탭 맨 위 주소(https://...firebasedatabase.app)를 넣어요.

## 2단계. GitHub에 올리기

```bash
# 폴더로 이동 (압축 푼 위치)
cd telepathy-game

git init
git add .
git commit -m "텔레파시 게임"
git branch -M main

# GitHub에서 새 저장소(예: oy-telepathy)를 만든 뒤 주소를 넣어요
git remote add origin https://github.com/내아이디/oy-telepathy.git
git push -u origin main
```

GitHub 저장소 > **Settings > Pages**
- Source: **Deploy from a branch**
- Branch: **main**, 폴더 **/(root)** > Save
- 1~2분 뒤 주소가 나와요: `https://내아이디.github.io/oy-telepathy/`

마지막으로 Firebase 콘솔 > Authentication > **설정 > 승인된 도메인**에 `내아이디.github.io` 를 추가해요. (안 하면 관리자 로그인이 막혀요)

> 저장소를 Public으로 만들어야 무료로 Pages를 쓸 수 있어요. firebaseConfig 값은 원래 공개되는 값이라 괜찮고, 실제 보호는 보안 규칙이 해요.

## 3단계. 리허설

1. `.../oy-telepathy/admin.html` 접속 > 관리자 로그인
   - 처음 들어가면 13개 팀과 예시 문제 11개가 자동으로 만들어져요.
2. **팀, 문제, 설정** 탭에서 내용을 바꾸고 각 탭의 저장 버튼을 눌러요.
3. **진행 화면 열기** > 프로젝터에 띄우고 F키로 전체 화면, **소리 켜기** 누르기
4. 휴대폰 2~3대로 QR 찍고 들어와 한 문제 돌려 보기
5. 리허설 뒤 관리자 페이지에서 **참가자 모두 내보내기**, **게임 초기화**

## 진행 순서 (스페이스바 하나로 진행)

대기 화면(QR) → 첫 문제 시작 → 3초 준비 → 투표(제한 시간, 마지막 5초 긴장 연출) → 자동 마감 → 결과 공개(두구두구 후 팀 카드 뒤집기) → 순위 보기 → 다음 문제 → … → 최종 결과(시상대)

- **시간 +5초**: 투표 중에 시간을 늘려요
- **이 문제 다시**: 그 문제의 투표와 점수를 지우고 다시 시작해요
- **문제 골라서 시작**(관리자 페이지): 원하는 문제로 바로 이동
- **게임 초기화**: 점수와 투표만 지우고 팀, 문제는 남겨요

## 점수 규칙

- 같은 팀에서 같은 답을 고른 사람이 **기준 이상**이면 그 문제의 난이도 점수를 받아요.
- 기준은 설정 탭에서 **인원 수**(예: 4명) 또는 **팀 접속 인원 대비 비율**(예: 60%) 중 골라요.
- 2지선다에서 7명 팀은 한쪽이 늘 4명 이상이라 4명 기준이면 거의 항상 성공해요. **5명 이상**이나 **비율 70%**를 추천해요.
- 전원이 같은 답을 고르면 **전원 일치 보너스**를 줄 수 있어요(기본 0점).
- 결과는 "결과 공개"를 누른 순간의 접속 인원과 투표로 계산해요.

## 알아 둘 점

- 진행 화면이나 관리자 페이지가 열려 있어야 시간이 끝났을 때 자동 마감돼요.
- 참가자 화면에는 다른 팀원의 선택이 결과 공개 전까지 보이지 않아요(보안 규칙으로 막혀 있어요).
- Firebase 무료(Spark) 요금제는 **동시 접속 100명**까지예요. 13팀 x 7명 = 91명 + 진행 화면 2개로 딱 맞아요. 더 많아지면 Blaze 요금제로 바꾸세요(이 정도 규모면 비용은 거의 0원이에요).
- 저장하는 정보는 닉네임, 팀, 투표뿐이에요. 행사 뒤 관리자 페이지에서 참가자를 모두 내보내면 지워져요.
- 사운드는 브라우저에서 직접 합성해서 저작권 걱정이 없어요. 브라우저 정책상 **소리 켜기**를 한 번 눌러야 나와요.
